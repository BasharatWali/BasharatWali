### About me

I build machine-learning systems end to end: preparing real-world data, training and fine-tuning models, and checking the results carefully. Each repository below comes with a write-up of the method, the numbers and the limitations.

- **Education:** M.S. Artificial Intelligence, SEECS, National University of Sciences and Technology (NUST), Islamabad
- **Focus:** fine-tuning LLMs (QLoRA, PEFT), medical imaging (MRI radiomics), computer vision and satellite time series
- **Best result so far:** rank 13 on the SemEval-2025 Task 8 (DataBench) leaderboard with a QLoRA-tuned CodeLlama-7B
- **Open to:** AI/ML engineering roles and research collaborations

### Featured projects

| Project | What it does | Result |
|---|---|---|
| **[TableTalk CodeGen](https://github.com/BasharatWali/TableTalk_CodeGen)** | Fine-tunes CodeLlama-7B-Instruct with QLoRA to answer questions about tables by writing one line of pandas code | **75.94** on DataBench, rank 13 (SemEval-2025 Task 8) |
| **[Parkinson's Detection from MRI](https://github.com/BasharatWali/Parkinson_Disease_Detection)** | PD25 atlas registration, subcortical radiomics, SVM feature selection and a Random Forest, with a Flask demo | **0.96** accuracy, **0.98** ROC AUC on 148 held-out scans |
| **[Crop Type Mapping](https://github.com/BasharatWali/Time-Series-Based-Crop-Type-Mapping)** | Temporal U-Net on a six-month Sentinel-2 series that maps Ontario farmland for an unseen year | 2021 crop map exported as a GeoTIFF and viewed in Earth Engine |
| **[Underwater Image Enhancement](https://github.com/BasharatWali/Underwater-Image-Enhancement)** | Reproduces DIRS-CLAHS and extends it with colour compensation, adaptive CLAHE and MSRCR | Benchmarked on UIEB with PSNR, SSIM, UIQM and UCIQE |
| **[Drug Recommendation with BERT](https://github.com/BasharatWali/Medicine_Rec_System)** | Matches symptoms to medicines with PubMedBERT and ClinicalBERT embeddings | LSH, SimHash and FAISS compared on speed and match quality |
| **[Multi-Task MLP](https://github.com/BasharatWali/Multi-Purpose-MLP-Classification-Regression)** | One PyTorch network that predicts age, gender and ethnicity from face images | About **75%** gender accuracy on the test set |
